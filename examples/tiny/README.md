# Tiny fixed-parameter BP example

Eight nodes, two communities, six pair edges and four triple edges. These manually specified inputs are independent of the withheld research datasets. See the root README for the exact command. The purpose is to check installation, input loading and output creation, not to reproduce a paper result.

`node_assignments.txt` provides illustrative labels for the separate sampling example: nodes 0–3 are in community 0 and nodes 4–7 in community 1. These are manually specified demonstration inputs. The root README includes fixed-parameter BP, learned-parameter BP-EM and synthetic-sampling commands.
